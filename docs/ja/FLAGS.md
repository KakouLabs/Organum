# フラグリファレンス

Organumでサポートされているリサンプラーフラグのリスト。大文字と小文字を区別せずに使用できます。

[한국어](../FLAGS.md) | [English](../en/FLAGS.md) | [日本語](FLAGS.md)

---

## フラグ一覧

| フラグ | 名称 | 範囲 | 中立 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `g` | ジェンダー | -100 ~ 100 | 0 | フォルマントシフト。正の値で低く、負の値で高くなります。 |
| `B` | ブレス | 0 ~ 100 | 50 | ノイズ（非周期性）の度合い。50がオリジナル、100でウィスパー、0でメタリック。 |
| `M` | モジュレーション | 0 ~ 100 | 100 | 元のピッチ変動（ビブラート）の保持率。 |
| `t` | トーンオフセット | -∞ ~ ∞ | 0 | ピッチの微調整（cent単位、100 = 1半音）。 |
| `A` | 振幅 | 0 ~ 200 | 100 | 音量。100が等倍。 |
| `P` | ピーク | 0 ~ 100 | 100 | ピークノーマライゼーションレベル。未指定時は0.99。 |
| `y` | ピーク (エイリアス) | 0 ~ 100 | 100 | `P`と同じピークパラメータの別名フラグ。 |
| `C` | クラリティ | 0 ~ 100 | 0 | 無声区間のノイズフロアを減少させます。 |
| `H` | ハーモニクス | 0 ~ 100 | 0 | 有声フレームの非周期性を減らして倍音を強調します。 |
| `D` | ダイナミクス | 0 ~ 100 | 0 | ダイナミックレンジ圧縮。 |
| `F` | フォルマントシフト | -24 ~ 24 | 0 | 半音単位のフォルマントシフト。`g`とは独立。 |

## 詳細

### B (ブレス)

`B50`が中立。`B > 50`でノイズを1.0方向に加え、`B < 50`で元のノイズを縮小します。

### g (ジェンダー)

周波数ドメインのワーピング: `factor = 2^(g/100)`

### F (フォルマントシフト)

半音ベース: `factor = 2^(F/12)`。`F12`でフォルマントが1オクターブ上昇します。

### H (ハーモニクス)

有声フレームの非周期性を二次曲線で減少させます: `ap *= 1 - (H/100)²`

### C (クラリティ)

無声/無音区間のノイズフロアを減少させます: `ap *= 1 - (C/100)`

### D (ダイナミクス)

ソフトニーコンプレッサーを適用します。Dが上がるほど閾値（threshold）が下がり（1.0→0.2）、比率（ratio）が上がります（1:1→1:4）。音量/ピークノーマライゼーションの前に適用されます。

### P / y (ピーク)

`P`と`y`は同じピークパラメータを設定します。最後に解析された値が最終的な値として適用されます。

### 自動ブレス (Auto-Breath)

`B`フラグとは別に、子音の開始部分に50msのブレスフェードインが自動的に適用されます。

---

## 使い方

OpenUtauのFlagsフィールドに直接入力してください。複数のフラグを組み合わせることができます（例: `g+10B60A120C30H50`）。
